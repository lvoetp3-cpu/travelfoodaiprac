課程特色

  • HTML / CSS
    建立語意化結構與 RWD 版面。
  • JavaScript
    處理事件、驗證規則與畫面更新。
  • jQuery / AJAX
    簡化 DOM 操作，讀取縣市 JSON 資料。
  • AI 協作
    練習與 AI 一起除錯、重構與撰寫註解，而不是只複製貼上。

報名提醒

  • 姓名 2～8 字；Email 需包含 @，長度 3～30 字。
  • 密碼 8～16 字，不會寫入 LocalStorage。
  • 手機須符合臺灣格式：09 開頭共 10 碼。
  • 感興趣課程至少選一項，上課方式必選一項。
  • 按下送出僅為前端模擬，不會寫入資料庫。
